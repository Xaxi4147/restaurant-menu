# Mini Project Work 3: Restaurant Menu Management

This is a local-only Ionic + Angular app for managing restaurant, cafe, or canteen menu items.

## What it implements

- Create menu item records
- Validate required fields
- Store records locally in `localStorage`
- Search by partial key on menu item name, case-insensitive
- Edit existing records
- Delete records after confirmation
- List view showing name, category, price, and availability

## Record fields

- id
- name
- category
- description
- ingredients
- allergens
- price
- available
- preparationTime
- imageUrl

## How to run

```bash
npm install
npm start
```

The app runs locally. It does not use a remote backend or external database server.
